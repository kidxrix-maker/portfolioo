FitBite — Meal Planning & Grocery App

Overview

FitBite is a meal planning and grocery app designed to help users make healthier eating decisions with less friction. I designed screens for Home, Menu browsing, and Recipe Search — built as an interactive Figma prototype with full navigation flows.

Design Process
01 · Research
User Flows & Needs
Identified core user tasks: browse recipes, plan meals, generate grocery lists
02 · Wireframe
Low-fidelity Sketches
Mapped out screen structures and navigation patterns before visual design
03 · Design
High-fidelity in Figma
Applied green-forward color palette, consistent typography, reusable UI components
04 · Prototype
Interactive Flows
Built prototype connections in Figma's Present mode to simulate a full user experience
05 · System
Design System
Created reusable components, color tokens, and type styles for consistency
06 · Review
Usability Reflection
Evaluated flows against core UX principles from Coursera curriculum
Key Design Decisions

I chose a green-forward color palette to visually reinforce the app's health-focused identity. The navigation was designed around a bottom tab bar for mobile thumb ergonomics. Components were built as Figma variants so they could be easily reused and adapted across screens — something I learned to prioritize for scalability.

Learnings

This project taught me how much design decisions compound — a small choice in the color system affects every screen. Building reusable components from the start saved enormous time during iteration. I also learned that interactive prototype testing reveals issues that static screens never show.

What I did

Collaborated with skincare brands, dermatology clinics, dental clinics, hair salons, and pharmacies across Seoul to design social media content — primarily for Instagram. Used Canva and Figma to create aesthetic marketing visuals that communicated brand identity to Korean audiences.

Approach

Every client had a different visual identity, so my first task was always to understand their brand personality — clinical and trustworthy vs. warm and lifestyle-focused. Design Exploration · UX Concept · 2024

K-Beauty App — UX Exploration

A personal design exploration applying UX principles from my Coursera training to a concept I'm genuinely passionate about: K-beauty discovery apps.

What this is

This is a self-initiated concept project — not a client project. I used it as a sandbox to apply and extend what I was learning in my UX certifications. I focused on onboarding flow design, personalization UX, and visual design language for a K-beauty product discovery app concept.

About the typeface

Asta Sans (formerly 42dot Sans) is a Hangul typeface by 42dot, designed around the asterisk symbol (*) — ASCII code 42 — which represents universality and openness in computing. The typeface balances sharp technical lines with user-friendly curves, built on the values of clarity, neutrality, and inclusiveness. Distributed free via Google Fonts and GitHub under SIL Open Font License 1.1.

What I analysed
Structure
Hangul type anatomy
Internal counters, stroke contrast, and how the square-ish counters maintain even gray value in body text
Concept
Design philosophy
How 42dot's identity as a tech company shaped the decision to balance precision with warmth
Application
Type specimen layout
Designed specimen pages showing the typeface at multiple weights, sizes, and in Korean body text

Design Exploration · Brand Identity · 2024

Skincare Brand Identity — Visual Concept

A self-initiated brand identity concept applying what I learned in my Identity Design coursework at SeoulTech — logo exploration, color systems, and typography.

What this is

A personal concept project inspired by my Identity Design course. I designed a brand identity from scratch for an imagined Korean skincare line — including logo sketches, color palette rationale, typography pairing, and how the identity would translate across packaging and social media.

Design thinking

I wanted to explore the space between clinical skincare and lifestyle aesthetics — a tension I observe in the Korean beauty market. The visual direction landed on warm ivory + soft terracotta as a way to feel both clean and approachable, with an editorial serif to signal quality without coldness.
